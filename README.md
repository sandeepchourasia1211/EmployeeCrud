# EmployeeCrud


requirement 1

Employee model class with properties : Name, Email,Age,Salary

Method that returns List of Employees(List<Employee>)


requirement 2.

create table tbl_employee with column : EmployeeId(int,Primary Key), Name Nvarchar(100), Age(int), Salary(decimal(18,2))
create store procedure for crud operations


requirement 3.
create asp.net core web api controller named EmployeeController with following api's
1.  GET/api/employee --Get all employee
2.  GET/api/employee/{id} --Get all employee by id
3.  POST/api/employee --add new employee
4.  PUT/api/employee/{id} --update all employee
5.  DELETE/api/employee/{id} --Get all employee

requirement 4.

1.html page with form to enter employee details (Name, Email,Age,Salary)
2. edit and delete button
3. submit button
